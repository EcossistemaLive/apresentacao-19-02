# 🎨 Squad: Design

Squad responsável pela **identidade visual e qualidade de design** de todos os documentos produzidos pelo sistema.

## 🎯 Missão

Manter o **Sistema de Design Unificado V6.0** da Live Consultoria como fonte de verdade para documentos da consultoria, e atuar como **auditor visual** para documentos gerados por outros squads fora do contexto da consultoria.

## 📐 Escopo Duplo

### Para a Live Consultoria
Aplicação integral do Guia de Estilo V6.0:
- Dark Mode (`#06192a`) + Verde Laser (`#00e800`)
- Tipografia Cinética (Poppins + Merriweather)
- Física de Interface (springs, refração, inércia)
- Assets oficiais (Logo, textura cubes.png)
- Rodapé: `© 2026 Live Consultoria` + `₢ Powered by Cléber Donato`

### Para outros Squads
Revisão com critérios universais:
- Consistência visual e harmonia cromática
- Hierarquia tipográfica e legibilidade
- Responsividade mobile (Thumb Zone, Lei de Fitts)
- Acessibilidade (contraste inteligente, Focus Visible)
- Performance (FCP < 50ms, Lazy Loading)

## 🔧 Comandos

| Comando | Descrição |
|---------|-----------|
| `/design-check [arquivo]` | Aplicar e validar guia de estilo Live |
| `/design-review [arquivo]` | Revisar documento externo (fora da consultoria) |
| `/design-validate [arquivo]` | Executar Checklist Elite V6.0 completo |
