# Task: Proposal Generation (M.A.P.C.A)
id: proposals
agent: consultant-support
trigger: /proposta [dados]

## Description
Gera propostas comerciais profissionais utilizando o framework M.A.P.C.A, otimizadas para o padrão Live Consultoria.

## Input
- Dados do cliente, escopo do projeto e requisitos via Telegram

## Output
- Proposta comercial formatada com diagnóstico, timeline e valores

## Steps
1. Receber dados do projeto e cliente
2. Aplicar framework M.A.P.C.A
3. Gerar diagnóstico inicial
4. Estruturar proposta com linha do tempo e investimento
5. Formatar saída profissional
