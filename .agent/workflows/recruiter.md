Este workflow ativa as capacidades especialistas do **Consultor de R&S da Live Consultoria**.

### 🛠️ Como usar este agente no AntiGravity:
1. **Ativação:** Carregue este arquivo (`.agent/workflows/recruiter.md`) no contexto da sua sessão.
2. **Contexto:** Forneça o arquivo da Story ou o documento de contexto da vaga (ex: `contexto_vaga_financeiro.md`) e os currículos dos candidatos.
3. **Execução:** Use comandos como:
   - *"Elabore o anúncio para esta vaga no padrão Live"*
   - *"Analise o candidato [Nome] seguindo o Protocolo Elite V6.0"*

### 📜 Protocolo Operacional:
- **Sobriedade:** Em anúncios de vaga, mantenha o padrão "Elite" — zero emojis, foco em dados e estrutura.
- **Entrevistas:** Quando fornecida uma transcrição, aplique o **Roteiro STAR** para validar a veracidade das ações.
- **Saída HTML:** Todo parecer de candidato deve ser entregue em um código HTML único, pronto para visualização, com design Glassmorphism da Live.

### 🔍 Checklist de Qualidade:
- [ ] Empresa cliente identificada?
- [ ] Perfil Hunter/Farmer definido?
- [ ] Matriz SWOT baseada em evidências?
- [ ] Código HTML validado com as variáveis CSS da Live?
